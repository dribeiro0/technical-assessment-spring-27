======================================================================
5. VIEW BY VIEW
======================================================================

  OVERVIEW
    First:   network status, line status, major disruptions
    Can:     open score explanation; open a line; open an alert; open a
             saved commute; change mode filter (subway/bus/...)
    Leads:   score -> explanation; vehicle count -> Live Map filtered;
             alert count -> Alerts; line -> Route details;
             disruption item -> that alert

  LIVE MAP
    First:   map of Greater Boston with live vehicle markers
    Can:     filter by mode/line/direction; search station or vehicle;
             click marker; follow vehicle; switch to list view
    Leads:   marker -> Vehicle details (popup / panel);
             station -> Station details; follow -> tracking
    List alternative carries the same data (09).

  SERVICE ALERTS
    First:   active alerts ordered by passenger impact
    Can:     filter by severity, route, "my routes", upcoming
    Leads:   alert -> affected route/stops on map; -> Route details

  ANALYTICS
    First:   live distribution chart (assessment chart, 07)
    Can:     choose mode/line scope
    Leads:   bar -> Route details; trends only once history exists,
             otherwise "collecting since <date>"

  MY COMMUTE
    First:   saved commutes with next departures and relevance
    Can:     add, rename, reverse, delete; start tracking
    Leads:   departure -> Tracking; alert -> alert detail

7. NAVIGATION AND JOURNEYS
======================================================================

  Global search
     +--> Station details -> departures | save station | start journey
     +--> Route details   -> route score | route map | alerts | analytics
     +--> Vehicle details -> predictions | follow | associated route

  Mobile flow:
    open -> personal commute overview -> (search | saved station |
    nearby, optional) -> direction -> upcoming departures -> select
    train -> waiting/tracking -> confirm boarding -> active journey ->
    approaching destination -> get-off alert -> journey complete

  Global: search finds any station, route, or vehicle from anywhere.
  Deep links to a route, station, or vehicle [PROPOSED].
  Mode switch always reachable; choice remembered on the device.

  Journey A - enthusiast checks a bad day
    Overview -> Red Line status "High" -> Route details -> sees
    suspension alert -> opens map at affected segment -> opens a
    stranded vehicle -> back to Overview

  Journey B - commuter leaving class (from planning) [MOCK]
    open app -> Saved: BU Central Green B eastbound, 3 min LIVE ->
    tap -> Tracking (3 min, 2 stops away) -> "I'm on this train" ->
    onboard (next stop, 9 min to Park Street) -> "Your stop is next"
    -> End

  Journey C - first-time mobile user, no location
    Home (no saved) -> "find a station" -> types "Kenmore" -> Station
    details -> departures -> save -> becomes a saved stop

  Journey D - assessment walkthrough path
    Overview -> Live Map -> filter Red -> click marker (popup fields)
    -> toggle auto-refresh / manual refresh -> Alerts -> Analytics
    chart -> My Commute (if built) -> resize to mobile width
