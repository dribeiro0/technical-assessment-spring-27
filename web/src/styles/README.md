# styles/

Global styling with Tailwind CSS v4.

**Will contain**
- `index.css`: the Tailwind import, design tokens (MBTA line colours, fonts, spacing, light and dark themes) and base styles. It replaces the template's `src/index.css` and `src/App.css`.

**Line colours (from the MBTA API)**

| Line | Hex |
|---|---|
| Red | `#DA291C` |
| Orange | `#ED8B00` |
| Green | `#00843D` |
| Blue | `#003DA5` |

- Text stays readable at 200% size.
- Respect the reduced-motion setting.
