# features/vehicles/

The vehicle list view (Sprint 3, DEC-027).

**Will contain**
- `VehicleListView.tsx`: a table of shown vehicles with line, route, direction, status and stop label, and update age. It respects the line filter.

**Why it exists**
- It carries the same information as the map for people who can't use the map, such as keyboard and screen-reader users (09_nonfunctional_requirements.txt, section 1).
- It also covers the README's "Service Alerts & Table" view example.
