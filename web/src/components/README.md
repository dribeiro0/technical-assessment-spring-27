# components/

Shared pieces used by more than one view.

| File                   | What it does                                                                                                                                                                                                                                                                                                                                            |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `LineStatusBadges.tsx` | Four badges with each line's status from official alerts. Each badge is also a filter button (R6).                                                                                                                                                                                                                                                      |
| `LineTree.tsx`         | The train list. Clicking a line filters the map; the caret expands it into its trains, named by destination, with stop and age. The selected train scrolls into view. It doubles as the non-map vehicle list (09).                                                                                                                                      |
| `TrainCard.tsx`        | The selected train's floating card: a countdown to the next stop and a strip of the stops ahead, filled up to the train (DEC-032), then fact chips and "More details" with the full rows and line alerts. Falls back to stop text without predictions. With a line filtered and no train picked, it shows that line's alerts. A bottom sheet on phones. |
| `StationCard.tsx`      | Tap a station on the map, or a stop on a train's strip: the next trains leaving that station, grouped by line and destination, with countdowns (DEC-040).                                                                                                                                                                                               |
| `CommuteCard.tsx`      | A saved commute as a card over the map (?commute=): when to leave, next departures (LIVE or SCHEDULED), the walk from the rider's location or their usual walk, and edit, reverse and delete (DEC-047, DEC-048).                                                                                                                                        |
| `CommuteDetail.tsx`    | The body of the commute card: the leave-time advice, departures and data source.                                                                                                                                                                                                                                                                        |
| `CommuteForm.tsx`      | Add or edit a commute: station, the lines that stop there, direction, optional destination, usual walk and buffer. Keeps saved values when lists fail to load.                                                                                                                                                                                          |
| `MyCommutes.tsx`       | The sidebar list of saved commutes; choosing one opens its card. Fetches nothing itself.                                                                                                                                                                                                                                                                |
| `AlertsListCard.tsx`   | Every MBTA alert as a card over the map (?alert=all), opened from the warning button: in effect now, then upcoming with dates. Says when alerts are unavailable (DEC-056).                                                                                                                                                                              |
| `AlertCard.tsx`        | One official alert as a card over the map (?alert=): effect, dates, closed stations, the MBTA's full text, labelled as an MBTA notice.                                                                                                                                                                                                                  |
| `CommuteAlerts.tsx`    | On the commute card: alerts that affect the trip, a count of those elsewhere on the line, or that alerts are unavailable (DEC-055).                                                                                                                                                                                                                     |
| `FloatingCard.tsx`     | The frame shared by the train and station cards: floats top-right on desktop, a bottom sheet on phones.                                                                                                                                                                                                                                                 |
| `FeedNotices.tsx`      | The error panel with Retry for a failed first load, the loading notice, and the banner explaining stale, failed, rate-limited or paused data.                                                                                                                                                                                                           |
| `AlertList.tsx`        | Official MBTA alerts, most severe first, with a coloured bar by severity.                                                                                                                                                                                                                                                                               |
| `StatusMark.tsx`       | Line status as a symbol plus text: ○ good service, ▲ minor issues, ■ major disruption.                                                                                                                                                                                                                                                                  |
| `Icons.tsx`            | Small inline icons.                                                                                                                                                                                                                                                                                                                                     |

**Rules**

- Everything works with the keyboard, with visible focus.
- Status is never shown by colour alone.
