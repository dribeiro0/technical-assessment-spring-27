# hooks/

React hooks that connect screens to data and shared state.

| File                        | What it does                                                                                                                                                                                                                                                                                                                                  |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `liveData.ts`               | The `LiveData` shape, the `FeedStatus` values and `useLiveData()`, which any component uses to read the shared live data from `app/LiveDataProvider.tsx`.                                                                                                                                                                                     |
| `polling.ts`                | The shared refresh rules: poll intervals, pausing, waiting out a rate limit, and retrying network hiccups (but never a rate limit).                                                                                                                                                                                                           |
| `useTripPredictions.ts`     | Upcoming stops and arrival estimates for the selected train, every 15 s while it stays selected.                                                                                                                                                                                                                                              |
| `useStationDepartures.ts`   | The next departures from the selected station, every 15 s while it stays selected.                                                                                                                                                                                                                                                            |
| `useViewParams.ts`          | Reads and writes `?line=` (the filter) and `?vehicle=` (the selection) in the URL, so both survive view switches and reloads (DEC-025). Also holds the selected station (`?stop=`); a train, a station and a saved commute (`?commute=`) are never selected at once. Moving the filter to another line deselects a train on a different line. |
| `useNetwork.ts`             | Line paths and stations, cached on the device for 24 h; retried every minute if loading fails.                                                                                                                                                                                                                                                |
| `useSavedCommutes.ts`       | The saved commutes and every way to change them, shared by every screen and kept in step across browser tabs. Warns when the browser refuses storage.                                                                                                                                                                                         |
| `useCommuteDepartures.ts`   | Departures for the open commute: live every 15 s, the timetable only when nothing is live, with loading, empty, failed and stale states.                                                                                                                                                                                                      |
| `useCommuteOptions.ts`      | Choices for the commute form: the lines at a station and the stations on a line.                                                                                                                                                                                                                                                              |
| `useCommuteFirstOnPhone.ts` | Opens a phone rider's saved commute card over the map on arrival (once per visit, plain landing page only).                                                                                                                                                                                                                                   |
| `useLocation.ts`            | The rider's position for the walking estimate: asked for only on request, refreshed each minute while a commute is open, never stored or sent.                                                                                                                                                                                                |
| `useHistoryStatus.ts`       | How EnRoute's own history collection is going (collector/), every 5 minutes; only Analytics reads it, so the map never depends on it.                                                                                                                                                                                                         |
| `useNow.ts`                 | A ticking clock for "8 s ago" labels and countdowns.                                                                                                                                                                                                                                                                                          |
| `useReducedMotion.ts`       | Whether the system asks for reduced motion (turns off gliding, map and chart animation).                                                                                                                                                                                                                                                      |

**Rules**

- An empty filter result and a failed refresh are different states and stay distinguishable (DEC-019).
- After a failed refresh, the last good data and its time stay on screen.
